ℹ Cómo agregar una carta

1. Busca el Pokémon

Escribe al menos dos letras y selecciona una sugerencia válida.

2. Acota la impresión base

Selecciona año e ilustrador. Después puedes reducir por numeración, colección y código.

3. Selecciona la impresión

Elige la carta cuya ilustración y datos más se parezcan a la carta física.

4. Indica idioma y tipo

El idioma corresponde a la carta que tienes: inglés, español, japonés, coreano, chino simplificado, chino tradicional, portugués u otro.

5. Agrega la fotografía

Si la API no tiene la imagen regional, carga o toma una fotografía. La carta conservará los datos de la impresión base y tu imagen personalizada.

6. Si no existe coincidencia

Usa “Crear sin coincidencia”. La carta se guardará igualmente y después podrás editar sus datos.
